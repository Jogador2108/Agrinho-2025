# Projeto Agrinho 2025 – Festejando a Conexão Campo-Cidade

Este projeto foi desenvolvido por Kauã Guilherme F. da Silva, aluno do 3º ano do ensino médio, para participar do concurso Agrinho 2025, na subcategoria Programação Front-End (HTML e CSS).

O tema do projeto, “Festejando a conexão campo-cidade”, busca mostrar a importância da integração entre o meio rural e o urbano, destacando como tecnologia e inovação podem unir esses universos para promover sustentabilidade, crescimento econômico e qualidade de vida para todos.

Construído exclusivamente com HTML e CSS, o site segue boas práticas de estruturação, semântica, estilização e responsividade. Apresenta navegação clara por âncoras, um formulário de contato simples e um design harmonioso, com cores que remetem ao campo (verde) e à cidade (vermelho), reforçando visualmente a temática.

O código está modularizado e comentado para facilitar manutenção e atualização. O site é responsivo, garantindo boa visualização em diferentes dispositivos, e foi publicado via GitHub Pages com a hashtag oficial #agrinho no repositório, atendendo a todos os requisitos do concurso.

Este projeto representa o compromisso de unir tecnologia e consciência ambiental para valorizar a conexão entre campo e cidade, fortalecendo a ideia de que juntos somos mais sustentáveis e desenvolvidos.
