Tema do Projeto

O site destaca a importância da conexão entre o campo e a cidade, mostrando como a cultura rural e a tecnologia urbana podem se unir para um futuro sustentável e inovador.

Objetivos

  • Demonstrar a integração do campo com a cidade através da tecnologia.
  • Promover a conscientização sobre sustentabilidade e inovação.
  • Oferecer uma navegação simples, acessível e responsiva para todos.

Sobre o Projeto

Este projeto foi desenvolvido por Kauã Guilherme F. da Silva, aluno do 3º ano B, para participar do concurso Agrinho 2025 na categoria de Programação Front-End. Utilizamos HTML e CSS para construir uma página moderna, organizada e responsiva.

O site foi planejado para apresentar de forma clara e bonita os conceitos de conexão entre campo e cidade, explorando cores e elementos visuais que remetem a esses dois universos.
